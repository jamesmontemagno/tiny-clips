# Tiny Clips for Linux

## Unreleased — developer preview

- Start with Screenshot or Record, then choose Region, Screen, or Window. One-capture permissions stay separate from sharing with agents. During recording the panel shows elapsed time and pause/stop controls; the screenshot editor keeps tool options out of the way of the image.

- Choose a screen/window with GNOME's portal, take and edit PNG screenshots, and record H.264 MP4 with optional microphone and system audio, pause/resume and recovery of closed segments.
- Browse local captures and opt into a paired, scoped Agent Control socket. Agents can use an already-authorized source but cannot open a picker or grant themselves access.
- Build the test Flatpak in CI and check installed codecs, output timestamps and end-of-file seeking; run the 30-minute synthetic endurance check on demand.
