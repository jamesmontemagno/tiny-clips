# Tiny Clips Marketing

Launch-video source, assets, rendering workflow, and the reusable Hype Video skill have moved to the
standalone [tiny-clips-marketing repository](https://github.com/jamesmontemagno/tiny-clips-marketing).
Open that repository to create or update Tiny Clips launch videos.

The independent [Studio launch snapshot](studio-launch/README.md) remains on this branch for the
Studio preview campaign. It includes its own rendering scripts and footage and does not depend on
the removed `hype-video` project.
